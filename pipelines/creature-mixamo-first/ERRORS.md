# Каталог решённых ошибок: гуманоид на Mixamo (задача 182)

Собрано заново по задачам, журналам существ (фонарщик, псарь, молотобоец, всадник), `pipelines/creature/ARTIFACTS.md`
и замечаниям пользователя в `journals/SESSION.md`. Каждая строка: **признак → причина → решение**.

- **E…** ловит автопроверка: `pipelines/creature-mixamo-first/check.sh <id>`.
- **M…** проверяется вручную: кадры (`tools/pose_sheet.tscn`, скрытый рендер) или по правилу.

Пороги автопроверки откалиброваны на принятых существах (молотобоец, фонарщик, псарь проходят без провалов)
и на отклонённых клипах молотобойца (`c_club_combo`, `shoulder_equip`, `old_attack` — ловятся).

## Вручную

### Манекен и подбор клипов

| Код | Признак → решение | Откуда |
|---|---|---|
| M01 | Клипы подбирать по образу оружия с листа (двуручный, древковое, одноручное + щит), а не «похожий жест». Кандидатов искать по локальному каталогу `catalogs/`, смотреть на манекене до модели. | 120, 158, 167 |
| M02 | Смешивать клипы из разных наборов (стойка из одного, руки из другого набора) — нельзя, решение пользователя. Руки из своей же стойки (`arms_from`) — можно. | 155 |
| M03 | Нет клипа — сказать «не могу». Движение кодом не изображать: копьё «само летает», тетива, рысь подделкой отклонены. | 157 (шаги 3, 7), 179 |
| M04 | Длинный замах в начале удара: `attack_from` / `trim_start`; клип слишком быстрый — `time_scale`. Позы клипа не менять. | 136, ARTIFACTS 23 |
| M05 | После удара повторный замах или поза: `recovery` (переход в стойку), `full_clip` для тяжёлого проноса. | 138 |
| M06 | Скачок рук при возврате из разового клипа в стойку: переход 1,0 с, а не 0,3. | всадник, 161 |
| M07 | Защита — по образу: лучнику уклон, а не блок; боксёрский «танец» — нет; защита не длиннее удара. | 68, 151 |
| M08 | Реакция и защита тянут руку со щитом или оружием: доля размаха `defend_calm`, `hurt_calm` (четверть), а не заморозка. | 39, 40, 60, 73 |
| M09 | Защита запаздывает: играть клип с того места, где поза уже принята (`defend_from`), старт раньше удара (`defend_lead`). | 152, ARTIFACTS 29 |
| M10 | Бег и шаг: скорость перемещения по стопам клипа (`walk_speed`, замер `pose_sheet`); бег, если путь длиннее половины хода. | 118, 144 |
| M11 | Атака с пути (разбег) — бить сходу, без остановки и шага назад. | 173 |
| M12 | Длинное оружие не отводит тело назад перед ударом: `no_backstep`. | 154 |
