# Каталог Mixamo через браузер

Задача 119. Статус: проба. Выход: `catalogs/mixamo/`.
Инструменты: браузер Chrome, CUA, Python 3 (стандартная библиотека).

1. Открыть авторизованную вкладку Mixamo, раздел Animations. Очистить поиск
   и жанровые фильтры, выбрать 96 записей на страницу.
2. Читать карточки из доступного текста страницы через браузерное расширение
   или accessibility Chrome. В сборе 2026-11-05 расширение обнаруживало вкладку,
   но чтение DOM завершалось ошибкой; использовано accessibility Chrome.
3. Для каждой карточки сохранить `name`, `description`, `type` (`animation`
   или `pack`). Для пакета описание — показанное число анимаций. Не удалять
   одноимённые записи. Сохранять страницы и порядок карточек.
4. Переходить видимой кнопкой следующей страницы. После перехода дождаться
   новых карточек и проверить номер страницы. Счётчик и пагинация могут
   обновляться позже карточек — на последней странице прочитать их повторно.
5. Сохранить UTF-8 JSON: `source`, `collected_at` (UTC ISO), `timezone`, `scope`,
   `total` (со счётчика сайта), `pages: [{page, entries: [...]}]`.
   В первом сборе данные из CUA сохранены через новый документ TextEdit
   в режиме обычного текста, в локальную папку проекта.
6. Запустить `python3 pipelines/mixamo-catalog/build.py`. Скрипт проверяет
   непрерывность страниц, число карточек, пустые поля, повторы целых страниц
   и совпадение общего количества. Он создаёт алфавитный `catalog.md`.
7. Обновить дату и объём в `catalogs/mixamo/README.md`, журнал и статус задачи;
   закоммитить. Не считать проверку метаданных проверкой самих движений.

Перед заменой будущим снимком сравнить количество и изменения; не объявлять
частичный сбор полным. Пакеты и отдельные клипы учитываются раздельно.
