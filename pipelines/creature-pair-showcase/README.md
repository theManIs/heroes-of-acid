# Составная витрина существ (задача 124)

Статус: проба. Инструменты: Godot, существующие модели и клипы.
Генерация и перенос анимаций сюда не входят.

1. Взять принятые игровые файлы псаря и собаки. Источники и имена клипов
   читать из `showcase.gd:NEW_CREATURES` и `hound_lab.gd`.
2. В `game/scenes/houndmaster_showcase.gd` показывать три раздела по восемь
   квадратов: псарь, собака, вместе. Сетка 4×2 в каждом разделе, общая прокрутка.
3. В парном наборе обе модели смотрят вперёд и стоят рядом. Циклы движения
   имеют общий период; укус начинается после командного жеста псаря. Реакция,
   защита запускаются вместе, затем каждый возвращается в стойку.
   При гибели псаря собака после короткой реакции разворачивается от него и
   убегает за край кадра на готовом клипе бега. Псарь остаётся лежать; после
   паузы обе модели возвращаются в исходное состояние для повтора (задача 125).
4. Для поглаживания собака остаётся в стойке. В парном квадрате правая рука
   псаря направляется к голове собаки через SkeletonIK3D, плавно подключённый
   к исходному клипу. Это коррекция контакта только для витрины, исходные
   модели и клипы не изменяются. Узел поддерживается установленным Godot 4.7.2.
5. Импортировать проект и снять по кадру разделов (`--section=master`, `hound`,
   `pair`, вместе с `--shot=<префикс>`). Проверить кадры, подписи, масштаб и контакты.
6. Обновить `SCENES.md`, журнал и задачу; закоммитить, затем открыть всю витрину:
   `godot --path game res://scenes/houndmaster_showcase.tscn`.

API: [SkeletonIK3D](https://docs.godotengine.org/en/stable/classes/class_skeletonik3d.html).
Сборный просмотр не добавляет существо в бой и не задаёт его гексы.
