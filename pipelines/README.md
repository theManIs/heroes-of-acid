# Пайплайны: перечень

Одна задача — один пайплайн. Перед работой найти строку здесь и назвать её пользователю.

**Правила:**

- Шаги разных пайплайнов не смешивать. Новое сочетание инструментов — это новая строка и новая папка, даже если отличается один шаг.
- Папка называется по задаче и инструментам: `<что делаем>-<инструменты>`.
- У пробного пайплайна свои файлы: основной он не трогает. Статус меняет только пользователь.
- Изменился процесс — в тот же ход обновить README пайплайна и эту таблицу.

**Статусы:** основной — так работаем; проба — идёт проверка; ждёт — проверим позже; копия — переносимое описание другого пайплайна.

## Финал работы над существом

В конце работы над любым существом подготовить и показать витрину
с выбранным только этим существом и всеми его выбранными анимациями одновременно. Витрину запустить
для просмотра пользователем и добавить её запуск в `SCENES.md`.
Интерактивное принятие выполняет пользователь. Общая витрина всех существ
не заменяет этот завершающий шаг. Уточнение пользователя: 2026-11-05.
