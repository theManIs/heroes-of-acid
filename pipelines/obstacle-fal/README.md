# Пайплайн: преграда на поле боя, Meshy через fal (проба, задача 101)

Ключ: `FAL_KEY` в `.env`, значение нигде не печатать. Запуск из корня проекта.

1. `python3 -I pipelines/obstacle-fal/generate.py <name> "<запрос>"`. Модель `fal-ai/meshy/v6/text-to-3d`, режим `full`, 4–7 минут, около 5 МБ. Результат: `obstacles/generations/<name>/`.
2. Скопировать `model.glb` в `game/assets/obstacles/<name>.glb`, запустить `godot --headless --path game --import`.
3. В `game/scenes/battle_test.gd` добавить в `OBSTACLES`.
4. Проверять на кадре из игры.

**Заметки:**

- Модель не растягивать: масштаб одинаковый по всем осям, размер под занятые гексы.
- Meshy плохо слушает форму: «гряда в линию» дала круглую кучу, поэтому гексы подбираются под готовую модель, а не наоборот.
- Несмотря на «no pedestal», дерево вышло с диском-подставкой: он спрятан под землю через `sink` в `OBSTACLES`.
- Точную цену в деньгах не смотрел: на странице fal указано 30 кредитов за модель в режиме `full`.

Стиль: без стимпанка, природные преграды. Бочка с кислотой пробовалась и убрана как перебор.
