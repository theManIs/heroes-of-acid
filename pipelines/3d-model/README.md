# Пайплайн: 3D-модель из нейросетей (общий)

Самодостаточный рецепт: от идеи до анимированной 3D-модели в игровом движке силами ИИ-агента. Без художника и без ручного моделирования. Проверен на четырёх гуманоидах (голем, упырь, котельщик, вампир) в проекте Heroes of Acid. Подробности и все найденные проблемы — в `pipelines/creature/ARTIFACTS.md` того проекта.

Инструменты: **ChatGPT** (картинка-концепт) → **Tripo API** (модель, риг, анимации) → **Godot 4.5+** (или любой движок с glTF).

---

## 0. Подготовка

- **Tripo:** аккаунт на `platform.tripo3d.ai` (это API, отдельно от сайта tripo3d.ai). Ключ `tsk_…` положить в `.env` (`TRIPO_API_KEY=…`), `.env` — в `.gitignore`. Баланс пополняется там же.
- **Python SDK:** `python3 -m venv .venv && .venv/bin/pip install tripo3d pillow`. Готовый скрипт: `pipelines/creature/stage2_tripo.py` из Heroes of Acid (состояние шагов в `tripo_state.json` — повторный запуск не платит дважды).
- **Документация Tripo** — одностраничное приложение, обычный fetch пустой. Читать как markdown: `https://developers.tripo3d.ai/en/docs/<страница>.md`, оглавление — `https://developers.tripo3d.ai/llms.txt`.
- **ChatGPT** — в браузере пользователя, где он уже вошёл (агент работает через расширение браузера).

## 1. Концепт (бесплатно — все итерации здесь)

1. **Описание** (кто, силуэт, детали, палитра, как двигается/бьёт). Согласовать с пользователем.
2. **Промпт** на английском = описание + технический хвост. Хвост не менять — от него зависит риг:

   ```
   Full body, front view, strict symmetrical T-pose: arms fully horizontal at shoulder height,
   straight out to the sides, legs apart with a clear gap between them, feet flat. The whole
   figure fits inside the frame with wide empty margin on all sides. No weapon, nothing held in
   the hands, nothing overlapping the body, no cloth hanging between the legs. Plain neutral
   light-grey background, soft even studio lighting, no cast shadows, no text, no ground.
   ```

3. **Генерация в ChatGPT.** Начинать сообщение с `Generate an image. Square 1:1.`
   - Вводить текст **настоящими нажатиями клавиш** (действие `type`), не вставлять скриптом: редактор ChatGPT не видит вставленный скриптом текст и не отправляет его.
   - Признак отправки — адрес сменился на `/c/…`.
   - Ждать короткими паузами по 10 с и проверять картинку (`img` ≥ 512 px); длинные циклы ожидания в скрипте страницы подвешивают вкладку.
   - Скачать: `fetch(img.src)` (blob) → ссылка `<a download>` → файл из «Загрузок» перенести в проект.
4. **Одна задача — один чат:** правки отправлять следующими сообщениями в том же чате. Разные задачи — разные чаты (можно параллельно). Когда задача закрыта — архивировать чат («…» у названия в списке слева → «Архивировать», проверить перезагрузкой; иногда архивирование откатывается — тогда пользователь вручную).
5. **Показать пользователю и остановиться** до подтверждения.

**Что знать о концептах:**
- Стиль текстом не управляется: «Warcraft 3 / Hearthstone» всё равно даёт полуреализм. Нужен референс-картинка.
- Телосложение — явно: «normal healthy proportions, not fat and not skinny» (иначе крайности).
- Риск для рига: длинные плащи, фартуки, повязки между ног, шланги-дуги от тела к рукам. Убирать на этапе концепта.
- Руки/кулаки упираются в края кадра — не страшно, поля добавит скрипт (15 %).

## 2. Модель, риг, анимации (Tripo API, платно)

| Шаг | Параметры | Кредиты |
|---|---|---|
| Модель по картинке | `model: v3.1-20260211`, `texture_quality: detailed`, **`face_limit: 20000`** (без него — 1,5 млн треугольников, 74 МБ) | 40 |
| Риг | `model: v1.0-20240301`, `rig_type: biped`, **`spec: tripo`** | 25 |
| Анимации | до 5 пресетов за задачу, `preset:biped:*` | 10 за штуку |

- **Риг:** `v1.0` даёт 90+ пресетов (`idle`, `walk`, `slash`, `chop`, `box_01`, `hit_to_body_01`, `hit_to_head`, `fall`, `fold_arms`, `afraid`, `scared_01`, `standing_relax`, `look_around`, `pitch_baseball`, …). `v3.0` — только 11. `spec: mixamo` с пресетами **не работает** (ошибка 1004).
- **«На месте» (`animate_in_place`)** — только для ходьбы/бега. У стоячих анимаций он прибивает таз, и ступни скользят. Ходьбу держать в отдельной задаче.
- Первая задача — с геометрией (`export_with_geometry: true`, это `<id>.glb`), остальные — без (`<id>-animsN.glb`), в движке подмешиваются к модели.
- Неудачные задачи бесплатны. Цена существа: модель + риг + 6–7 анимаций ≈ **105–135** кредитов.
- Не брать: `hurt` (существо садится на землю), `football_save` (прыжок — уносит тело), упражнения на полу (`cross_body_crunch`, `press-up`, `sit`, `swim`, `dive`), `turn`, `run`/`jump` без нужды.

**Подбор анимаций под характер.** Любое похожее движение, не обязательно боевое (бросок мяча `pitch_baseball` — удар когтями). Предлагать 3–5 кандидатов, заказывать **по одному**. До показа проверить по данным: смещение таза (> 0,2 — таскает тело), наклон корпуса (не лежит ли), длина, где нужный кусок (замер по костям).

## 3. Импорт в движок (Godot)

1. Положить GLB в ассеты, импорт.
2. **Текстуры:** Tripo отдаёт 4096×4096; Godot извлекает их без сжатия (8–22 МБ на текстуру). В `.import` каждой: `compress/mode=2`, `process/size_limit=2048` → 2,8 МБ, разницы в кадре нет.
3. **Модель смотрит по +X**, не по +Z — поправка поворота −90°.
4. Анимации второго файла — переписать пути треков на скелет основной модели.

**Типовые артефакты и решения** (все — один раз в общем классе существа):

| Симптом | Причина | Решение |
|---|---|---|
| «Доезжает» после остановки | таз в анимациях смещён относительно idle | выровнять трек `Hip` по idle (циклические — по среднему, разовые — по первому ключу) |
| Тело сбоку от точки существа | таз в idle не над началом координат | сдвинуть модель так, чтобы таз был над точкой |
| Ступни скользят при ходьбе | скорость ≠ шаг анимации | подогнать скорость (у нас 1,0 м/с при росте 2 м) |
| Разовые анимации по 6–14 с | так у Tripo | ускорять до ≤ 3 с; длинные — играть кусок |
| Удар «позирует» в конце | анимация досматривается | через ~0,3 с после попадания плавно в idle |
| Момент попадания | — | кадр самого быстрого выброса кисти вперёд, не самой дальней точки |
| Защита/смерть уносят тело | пресеты без «на месте» | держать таз над точкой, пока играется защита и пока существо мертво (уклоны — не держать) |
| Мёртвый парит/проваливается | физики нет | только у мёртвого: нижняя кость не ниже ~0,12 м |
| Обводка с мусором внутри | «вывернутая оболочка» на сложной сетке | стенсил-обводка движка (Godot 4.5+ `STENCIL_MODE_OUTLINE`) |
| Смена модели тормозит | загрузка с диска каждый раз | держать загруженные модели в кэше |

## 4. Пиктограмма

Снять модель в стойке idle, лицом в камеру, голова и плечи, 256×256 (в Heroes of Acid — `game/tools/icon_shot.tscn`, кадр подстраивается фокусом от кости `Head`). После снимка — переимпорт, иначе движок покажет старую картинку.

## 5. Чек-лист готовой модели

- [ ] Концепт утверждён, чат ChatGPT заархивирован
- [ ] ≤ 20 тыс. треугольников, текстуры 2048 со сжатием
- [ ] Смотрит туда, куда идёт; не «доезжает»; ступни не скользят
- [ ] Удар попадает в цель, реакция и защита — в момент попадания
- [ ] Защита и смерть не уносят тело с места; мёртвый лежит на земле
- [ ] Пиктограмма снята и переимпортирована
- [ ] Время и кредиты записаны в отчёт
