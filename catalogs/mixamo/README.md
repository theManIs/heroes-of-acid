# Локальный каталог Mixamo

Снимок доступного каталога Animations от **5 ноября 2026 года (Asia/Yerevan)**.

- `catalog.json` — все 26 страниц в исходном порядке: название, описание, тип записи.
- `catalog.md` — таблица по алфавиту со ссылками на поиск Mixamo.
- Объём: **2 484 записи**, из них **2 439 анимаций** и **45 пакетов**. Совпадает со счётчиком сайта; последняя страница — 2401–2484.

Поиск из корня проекта:

```sh
rg -ni 'pointing|petting|block|idle' catalogs/mixamo/catalog.md
```

Описания сохранены на языке Mixamo. Поиск русскими словами их не переводит.
Одинаковые названия и даже одинаковые пары «название + описание» не объединяются:
это могут быть разные варианты. Ключ `p01-01` означает страницу и позицию
в этом снимке; постоянного идентификатора клипа в нём нет.

Полнота относится ко всем записям доступного каталога без поисковых и жанровых
фильтров на дату сбора. Состав каждого пакета отдельно не раскрывался.
Файлы анимаций не скачаны, движения на моделях проекта не проверены.
Для выбора сначала искать здесь, затем открывать Mixamo для просмотра и скачивания.

Обновление: [пайплайн](../../pipelines/mixamo-catalog/README.md).
