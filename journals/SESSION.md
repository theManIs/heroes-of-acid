# Session journal — heroes-of-acid

## Scope

Пошаговая стратегия в духе «Героев 3»: свой сеттинг, урезанный контент, сетевая игра 1 на 1. Стадия — прототипирование: пайплайн существ и тестовая сцена в Godot.

## Где что лежит

- `AGENTS.md` — правила работы (копия `~/Documents/projects/AGENTS.md`, основной файл там).
- `docs/game-aspects.md` — **источник правды по игре**: решения пользователя по 16 аспектам (существа, замки, герои, ресурсы, карта, нейтралы, бой, магия, навыки, артефакты, время, победа, сеть, ИИ, карты, стиль).
- `docs/estimate.md` — **устарела**: первая оценка на допущениях ассистента (браузер, TypeScript и т. п.), пользователь её не принял. Будет пересобрана задачей 2.
- `CONCEPT.md` — концепция игры для передачи наружу (сводка `docs/game-aspects.md`).
- `TASKS.md` — задачи.
- `pipelines/creature/ARTIFACTS.md` — все найденные проблемы пайплайна и их решения (читать перед новым существом).
- `pipelines/creature/` — пайплайн существа (этап 1 концепт в ChatGPT, этап 2 Tripo API), `creatures/<id>/` — рабочие файлы существа.
- `game/` — проект Godot 4.7; арена проверки существ (голем, упырь, котельщик), сборка Windows — `builds/`.

## Decisions

- Платформа: ПК, движок Godot.
- Команда: пользователь + ИИ-агенты (Codex, Claude, Grok).
- Арт: 3D через нейросетевой пайплайн (генерация + скиннинг + риг в одном пайплайне, 3–4 итерации шлифовки), стиль — насыщенный реализм (не стилизация). Портреты героев — 2D от нейросети.
- Замки: Инквизиция, Ковен, Изобретатели (мрачный дизельпанк, аугментации, механизмы); идеи на потом — Погост, Чумной культ.
- Сеттинг: Тёмное средневековое фэнтези: вампиры, франкенштейны, инквизиция, чумные доктора, мортуарный (погребальный) вайб.
- Детали по каждому аспекту — в `docs/game-aspects.md`.
