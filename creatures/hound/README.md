# Собака (hound): журнал работ

Рабочее имя `hound`. Часть существа «Псарь с собакой» (задача 109). Здесь ничего не удаляем, пока не ясно, что пригодится.

- `concept/v1.png`, запрос в `concept/v1.json`: `fal-ai/gpt-image-1.5` через `pipelines/creature-quadruped/concept.py`. Принят пользователем.

## Два баланса

Studio и API считаются отдельно. На момент записи: Studio 105 (было 200), API 850 (было 925).

## Что выяснилось про Studio

- Сгенерированная в Studio модель: экспорт только по подписке Pro.
- Загруженная своя модель: экспорт открыт, лимит на плане Free, было 15 выгрузок.
- Первая загрузка пропала без сообщения, вторая прошла (id `c56d5200-…`).
- Риг: типы Humanoid и Other, 20 кредитов. Типа Quadruped в интерфейсе нет.
- Анимация: пресет Walk применяется бесплатно.
- Text to Motion: 20 кредитов, клип «Custom Motion» показан на манекене-человеке, к собаке не применился. Сообщения об ошибке нет. Причина не установлена.
- В окне экспорта есть переключатель «Export Skeleton» с короной (Pro).

## Сравнение скелетов (`pipelines/creature-quadruped/bones.py`, `joints.py`)

Файлы:

- API: `tripo/api-v3.0-20260909/rig/*_model.glb` (риг `quadruped`, `v3.0-20260909`, `spec: tripo`, 25 кредитов API) и `walk/*_model.glb` (`preset:quadruped:walk`, 10 кредитов API).
- Studio: `tripo/studio-other/hound-walk-noskeleton-toggle.glb` (тип Other, выгружен с выбранной Walk, «Export Skeleton» выключен, потрачена 1 из 15 выгрузок).

| | API `quadruped` | Studio Other |
|---|---|---|
| Костей | 33 | 34 |
| Четыре лапы | да | да |
| Голова | `Head_0–3` | `Head_0–3` |

| Стопы | по 5 костей на задних лапах | по 4 кости |
| Анимация в файле | ходьба: 2,6 с, 16 костей, хвост и конец передней лапы не двигаются | нет, 0 анимаций, хотя выбрана Walk |
| Поза покоя | есть | у узлов смещения нулевые: без «Export Skeleton» скелет неполный |

Выводы:

- **Лишней кости у таза нет.** Длинные кости в просмотрщике — это связи от `Root` на земле к тазу, задним лапам и хвосту. Так у обоих ригов. Мой прежний вывод о «лишней кости» был неверным.
- **Челюсти нет ни у кого.** Пасть своими костями не откроется.
- **Бесплатная выгрузка из Studio анимаций не даёт:** в файле 0 анимаций. Скелет на плане Free выгружается неполным: переключатель «Export Skeleton» требует Pro.
- **Рабочая анимация в руках пока одна:** ходьба из API (`walk/*_model.glb`). В Godot ещё не проверена.
