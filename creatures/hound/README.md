Рабочее имя `hound`. Часть существа «Псарь с собакой» (задача 109). Здесь ничего не удаляем, пока не ясно, что пригодится.

## Два баланса

Studio и API считаются отдельно. На момент записи: Studio 105 (было 200), API 850 (было 925).

## Что выяснилось про Studio

- Сгенерированная в Studio модель: экспорт только по подписке Pro.
- Загруженная своя модель: экспорт открыт, лимит на плане Free, было 15 выгрузок.
- Первая загрузка пропала без сообщения, вторая прошла (id `c56d5200-…`).
- Риг: типы Humanoid и Other, 20 кредитов. Типа Quadruped в интерфейсе нет.
- Анимация: пресет Walk применяется бесплатно.
- Text to Motion: 20 кредитов, клип «Custom Motion» показан на манекене-человеке, к собаке не применился. Сообщения об ошибке нет. Причина не установлена.
- В окне экспорта есть переключатель «Export Skeleton» с короной (Pro).

Выводы:

- **Лишней кости у таза нет.** Длинные кости в просмотрщике — это связи от `Root` на земле к тазу, задним лапам и хвосту. Так у обоих ригов. Мой прежний вывод о «лишней кости» был неверным.
- **Челюсти нет ни у кого.** Пасть своими костями не откроется.
- **Бесплатная выгрузка из Studio анимаций не даёт:** в файле 0 анимаций. Скелет на плане Free выгружается неполным: переключатель «Export Skeleton» требует Pro.
- **Рабочая анимация в руках пока одна:** ходьба из API (`walk/*_model.glb`). В Godot ещё не проверена.

## Что пишут про анимации четвероногих (проверено 2026-11-04)

- Форумы: обсуждений Text to Motion на четвероногих не нашёл.
- Блог Tripo про животных: только пресеты, режим Text to Motion там не упомянут; экспорт со скелетом и анимациями через «Export Skeleton». Блог называет тип Quadruped, в интерфейсе Studio его нет, есть Other.
- Документация API: для ригов `v2.5` и `v3.0` «16 universal presets»; для всех типов ригов перечислены `preset:idle`, `run`, `slash`, `hurt`, `fall` и другие, для четвероногих явно назван только `preset:quadruped:walk`. На собаке проверено, см. ниже.
- Meshy на fal: риг только для гуманоидов. Meshy на своём сайте: тип Quadruped Dog, анимаций для него меньше, список не найден.

## Text to Motion на четвероногих: итог проверки

Новых кредитов не тратил. Что видно в Studio:

- Подсказка режима дословно: «Create custom animations from text/videos. For best results, use a humanoid character in a clean T- or A-pose.»
- Сгенерированный клип и окно Multi-stage Motion показаны на манекене-человеке, примеры запросов про удар рукой и кувырок.
- Клик по клипу не отправляет запроса на сервер и не ставит отметку. Клик по пресету Walk запускает Retargeting.
- Сообщения об ошибке нет. Запрета для четвероногих в явном виде тоже нет.

Вывод: режим генерирует движение человека и к собаке не переносится. Считаем, что для четвероногих он не работает. Прямого заявления Tripo нет.

Донор для проверки: лисица Khronos, `donors/fox/`, 24 кости, Survey, Walk, Run. Скрипт: `pipelines/creature-quadruped/bind_donor.py`, Blender без окна, бесплатно.

Проверено по одному кадру каждой анимации в лаборатории, вживую в движении не смотрел. Ступни на земле и прилипание не проверены. Текстура сохранилась. Хвост на ходьбе торчит вверх: так у лисы.

Лицензия лисицы смешанная (CC0 и CC-BY), для игры её не брать, это только проверка метода. Стойка есть (Survey: озирается). Укуса, реакции и смерти у лисицы нет: для них нужен другой донор.

## Донор хаски: полный набор

`donors/husky/`, набор Quaternius Animated Animal Pack, на poly.pizza и странице набора указано CC0. Результат: `donors/husky/hound-on-husky.glb`.

Анимации: Idle, Idle_2, Idle_2_HeadLow, Attack, Walk, Gallop, Gallop_Jump, Jump_ToIdle, Idle_HitReact_Left, Idle_HitReact_Right, Eating, Death. Каждая в файле дважды, вторая копия с приставкой `AnimalArmature|`. 49 костей, в том числе уши и хвост.

На кадрах лаборатории цела сетка в стойке, укусе, ходьбе, беге, реакции и смерти; в движении сам не смотрел. Пропорции подгоняются: кости хаски сжаты по высоте до 0,53, ступни и скольжение не проверены. Челюсти нет, укус — бросок головы.

Ошибка лаборатории, не привязки: у скелета хаски масштаб 100, сетка со скелетом его не использует, а размер считался с ним, и собака была крошечной. Исправлено в `hound_lab.gd`.
