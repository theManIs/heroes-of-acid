## Шаг 3 — «едет» (2026-11-06)

Клипа езды нет ни в Mixamo, ни в Tripo. В витрине два квадрата «едет»: всадник в сидячей стойке
(`ride_still` — шагом, `ride_idle` — рысью), а движение даёт конь-макет: корпус подпрыгивает
(0,03 / 0,07 м), чуть качается, диагональные пары ног переставляются (1,6 / 2,6 шага в секунду).
У настоящего коня это будут клипы донора; всадник при этом просто едет на нём в своей стойке.
- Рысь переделана по замечанию пользователя («опытный наездник так не трясётся»): клип `ride_still`, корпус всадника
  берёт 35 % подпрыгивания коня, на каждый второй шаг привстаёт (облегчённая рысь). Клип `ride_idle` для езды не годится.
- Вариант «корпус берёт 35 %» отклонён: конь трясётся, всадник неподвижен. Теперь всадник снова едет вместе с конём
  в клипе `ride_still` и на рыси мягко привстаёт. Вывод: без настоящего клипа езды процедурная подделка остаётся подделкой.
