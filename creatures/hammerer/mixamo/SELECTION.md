# Молотобоец: выбранные клипы Mixamo

Источник: Great Sword Pack, 51 animations, X Bot, FBX Binary, T-pose, 30 fps,
без сокращения ключей. Скачан через Chrome 2026-11-05; исходный ZIP сохранён.
Названия и типы предварительно найдены в `catalogs/mixamo/catalog.md`.

| Файл в пакете | Игровое имя | Назначение |
|---|---|---|
| great sword idle.fbx | idle | Двуручная стойка |
| great sword walk.fbx | walk | Ходьба с двуручным хватом |
| great sword run.fbx | run | Бег с оружием |
| great sword slash (3).fbx | attack | Площадной удар по трём соседним гексам; возврат в стойку исправлен в 138, длина 1,63 с |
| Great Sword Downward Slash.fbx | attack_point | Отдельный двуручный удар сверху вниз по одной цели; исходник Mixamo, обрезан боковой замах до 0,5 с, оставшийся фрагмент замедлен ×1,5; длина 1,15 с |

Это исходники движения мечника, адаптированные к отдельному молоту, а не
специально снятые клипы молота. Горизонтальное перемещение таза удалено:
пакет не предлагает In Place в диалоге скачивания; вертикальная работа таза
сохранена. Измеренная скорость ходьбы 1,18 м/с при росте 1,9 м.
Ноги согласованы с позой Mixamo; поправка кисти для лука выключена.

Молот жёстко расположен по центрам ладоней, при расхождении рук в смерти
остаётся привязанным к правой кисти. Кандидаты slash/slash (2), impact и
blocking (2) сохранены в исходном пакете, в выбранную витрину не входят.

136: `great sword attack` отклонён пользователем. Slash (4)/(5) дают широкие
взмахи; отдельно скачанный `Bayonet Stab.fbx` (Without Skin, 30 fps, none)
разворачивает молот назад из-за обратного расположения рук. Эти кандидаты
не используются. Самодельный тычок также отклонён и удалён. По указанию
пользователя точечный режим использует отдельный вертикальный удар.
Повтор `great sword slash (3)` отклонён из-за широкого замаха, alias удалён.
Через активный Chrome скачаны Bash, Standing Melee Attack Downward и
Great Sword Slash с описанием **Great Sword Downward Slash**. Первые два
одноручные и не используются. Последний сохранён с уточнённым именем
`Great Sword Downward Slash.fbx`: FBX Binary, Without Skin, 30 fps, none,
настройки Mixamo по умолчанию. Источник — поиск Great Sword Slash,
выбран именно результат с описанием Downward, а не Power/Low/Combo.

В сборке сохранены ключи исходника начиная с 0,5 с, где оружие уже поднято;
начальный боковой размах отсечён. Время оставшихся ключей растянуто ×1,5,
позы не изменены. Длина 1,15 с, удар в 0,25 с (исходные 20/30 с),
impact 0,2173913; reach 1,6 м. Подключён в обе арены и отдельную ячейку
витрины. Ручное принятие пользователем впереди.

138: у площадного движения сохранены исходные ключи до 0,9333 с, включая
попадание в 0,9167 с. Повторный подъём после контакта заменён переходом
в стойку за 0,7 с. Длина 1,6333 с, impact 0,56122449. Настройки сохранены
в `clips.json:recovery`, сборка воспроизводима. Коррекция относится только
к площадному attack; у attack_point теперь свой исходник.

137: прежний idle (2) заменён на idle (3). Отклик должен запускаться при
наведении на бездействующее существо (определение из задачи 114).
Причина отсутствия: клип был подключён к витрине, но в аренах не было
запуска по наведению. Ошибочная отдельная кнопка удалена. В обеих аренах
курсор над союзной моделью запускает полный клип с обычной скоростью один раз на вход, только
из стойки; движение, удар и получение урона прерывают его обычным образом.
В витрине тот же клип повторяется в ячейке «Отклик».
