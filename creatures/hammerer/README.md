- 136: точечный удар — локально созданный двуручный тычок из стойки Mixamo.
- 137: отклик idle (3), 3,6 с; кнопка «Отклик» в тесте существа, без расхода хода.

- Ручное принятие сцены пользователем впереди. Дальность обычного хода пока
  3 гекса, как у тяжёлого отряда; фракция и итоговый баланс не назначены.
