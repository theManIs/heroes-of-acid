# Вампир (Ковен)

- Замок: Ковен. Вампирская знать, хозяин упырей; элита — сильный, быстрый, высокомерный.
- Силуэт: высокий, худощавый (не тощий), прямая аристократическая осанка; длинные пальцы с тёмными когтями.
- Детали: мертвенно-бледная кожа с синевой, запавшие красные светящиеся глаза, клыки, зачёсанные назад тёмные волосы с проседью; чёрно-бордовый камзол XVIII века со стоячим воротником, кружевное жабо с пятном крови; перстень с рубином, родовая брошь-медальон; узкие штаны, высокие сапоги.
- Плащ: без длинного плаща (риск для рига) — только короткая пелерина до лопаток.
- Палитра: чёрный, глубокий бордовый, мертвенно-белый; акцент — красные глаза и рубин.
- Удар: когтями наотмашь, хлёстко. Кандидаты: `slash`, `chop` кусочком, `front_kick_01`.
- Стойка: `standing_relax` или `fold_arms`. Защита: `hit_to_side` кусочком.
