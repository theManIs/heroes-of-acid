# Существа

По папке на существо:

- `concept/` — описание, промпты, концепты, виды для Tripo.
- `references/` — референсы существа (список в `references/README.md` в корне).
- `tripo/` — модели и риги от Tripo, отчёт, номера задач.

Игра грузит файлы из `game/assets/creatures/<id>/`. Анимации общие: `game/assets/animations/`.
